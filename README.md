# AI-Powered Data Analyst

Upload a CSV or Excel file and explore it in plain English.
Currently: upload, preview, data-quality metrics, column profile and summary stats.
Planned: automated cleaning, natural-language-to-SQL queries, charts and AI insights.

## Run locally

    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    streamlit run app.py

## Tech stack
Python, Pandas, NumPy, Streamlit, Plotly
